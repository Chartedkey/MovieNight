## Movie Night 0.3.13

Добавлено удаление сохранённой ночи с подтверждением.

- «Удалить ночь» доступно в сохранённых ночах и подготовке. Перед удалением показаны дата и фильмы; отмена сохраняет план.
- Удаляются только план и его задачи. Просмотры, оценки, очередь, ближайшие, фильмы и субтитры сохраняются.
- Ночь с незавершённым переносом нельзя удалить до восстановления исходника при необходимости и закрытия записи переноса.
- Удалённый план нельзя восстановить или использовать для отмены его результатов.

Функции переноса в «Сегодня» из 0.3.12 сохранены. Старый релиз 0.3.12 удалён с GitHub по согласованию с владельцем.
