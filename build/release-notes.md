При конфликте имён в «Диски → Названия» теперь понятно, что помешало переименованию.

- Вместо короткого «имя занято» показаны полный исходный и занятый путь.
- Из сообщения можно открыть исходник или ввести другое имя. Сохранение нового предложения убирает прежнюю ошибку строки.
- Случай изменения только регистра букв на Windows объясняется отдельно.

Существующие файлы и папки не перезаписываются. Совпадение имени не считается доказательством одинакового фильма.

Проверено: 255 тестов, включая сохранность обеих копий и библиотечных связей, вывод путей и ручное предложение имени.
