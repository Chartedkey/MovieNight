# Единые имена режиссёров

Статус: реализовано в исходниках после 0.3.10, ещё не выпущено. Новая сборка отдельно согласуется с владельцем.

Цель: привести отображаемые имена к привычному виду и сохранить поиск по исходным написаниям. Перевод не меняет человека в TMDB и не требует повторного импорта библиотеки.

## Идентичность и имена

| Данные | Назначение |
| --- | --- |
| `director.id` / ключ `directors` | Постоянный TMDB person ID; используется для запросов и связей |
| `userName` | Личное имя пользователя, имеет приоритет отображения |
| `tmdbName` | Сохранённое имя источника |
| `aliases` | Прежние имена и загруженные варианты для поиска |
| `sortSurname` | Необязательная фамилия для сортировки; без неё используется последнее слово имени |
| `nameReviewed` | Пользователь проверил имя; старые личные имена без этого поля считаются проверенными |

`name` остаётся текущим отображаемым значением для совместимости. Фильмы, их `dir`/`directorIds`, очереди, оценки, избранное, желания, планы и файлы не пересоздаются. Разные ID с одинаковым именем не объединяются. Кинематограф определяется странами фильма, а не языком имени.

## Общий редактор

В библиотеке рядом с добавлением находится обычная тёмная кнопка «Имена режиссёров». Открывается большое окно:

- Фильтры «Без кириллицы» (по умолчанию), «Ещё не проверены», «Есть черновик», «Все режиссёры». Кириллица — лишь способ найти строки, а не доказательство русского имени.
- Поиск по текущему имени, вариантам, предложению и связанным фильмам.
- Текущее имя, имя TMDB, ID и ссылка на профиль; поля отображаемого имени и фамилии сортировки; предпросмотр «было → станет».
- Первые три фильма с возможностью показать остальные; обычная тёмная кнопка «Характеристики фильма» открывает общую разметку `nightTags` и возвращает в редактор.
- По 20 режиссёров с кнопкой продолжения. Поиск и выбранные предложения относятся ко всей библиотеке.

«Загрузить варианты TMDB» запрашивает `/person/<ID>` и добавляет варианты в поиск. Предложение и имя библиотеки автоматически не заменяются. Вариант можно выбрать кнопкой или ввести самостоятельно. Загрузка требует доступа к TMDB; ручная правка и применение работают локально. Автоматического перевода/транслитерации нет.

## Черновики и применение

Правки автоматически сохраняются с небольшой задержкой в `directorNameDrafts`, отдельно от действующих имён. Кнопка «Сохранить черновик» и обычное закрытие редактора дожидаются записи. Перед завершением приложения следует дождаться «Черновик сохранён». Сохранённые черновики восстанавливаются после перезапуска.

Изменение текста снимает проверку строки. Пользователь отмечает «Проверено — выбрать для применения». Пустое имя можно оставить в непроверенном черновике, применить его нельзя. Длина имени и фамилии ограничена 150 символами.

«Применить выбранные» показывает отдельный предпросмотр всех отмеченных строк, включая скрытые поиском или фильтром. После подтверждения имена и фамилии сортировки записываются одним сохранением. Исходные написания остаются в `aliases`. Библиотека, алфавит и подбор используют новые имена; известные ID вариантов дискового разбора также разрешаются через сохранённые имена.

Черновик содержит исходные поля и их отпечаток, токен поколения и редакцию. Применение проверяет и исходное имя, и именно показанную редакцию предложения. Устаревшее сохранение не восстанавливает уже применённый или сброшенный черновик. Если имя изменилось после начала работы, «Обновить исходное имя» сохраняет введённое предложение, но снимает проверку: его нужно проверить заново. «Сбросить предложение» удаляет только черновик строки.

## Отмена и сохранность данных

`directorNameHistory` хранит пакет применения: время, ID, прежние поля имён и отпечаток результата. В истории доступна отмена с подтверждением. Возвращаются только имена/фамилии/признак проверки; поздние оценки, разметка, очереди и планы не откатываются. Накопленные варианты поиска сохраняются.

Если имя уже изменено позднее, отмена отклоняется целиком. Применение также сначала проверяет все строки и лишь затем меняет данные. При ошибке записи сервис восстанавливает прежние имена, черновики и историю в памяти. Проверки выполняются на временных базах, без пользовательских файлов и настоящего ключа TMDB.

Код: `src/director-names.js`, общий отпечаток `src/director-identity.js`, интерфейс `renderer/director-ui.js`. Новые методы включены в явный список разрешённых IPC-вызовов. Существующая индивидуальная кнопка «Имя режиссёра» сохраняется.
