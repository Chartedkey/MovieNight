# Инструкции для разработки Movie Night

- Перед работой прочитайте [полное описание программы](docs/PROGRAM.md): реализованные функции, ограничения, модель данных, план и правила выпуска.
- При изменении поведения обновляйте соответствующие разделы `docs/PROGRAM.md`. Отделяйте готовые возможности от планов и вопросов, требующих решения владельца.
- Каждая новая сборка версии и публикация релиза требуют явного согласования с Денисом. Согласование одной версии не распространяется на следующие. Без согласования не повышайте версию и не запускайте упаковку/публикацию.
- Учитывайте автоматизацию: push/PR запускает Windows CI с упаковкой; изменение `package.json` в main запускает выпуск. Для изменений только документации используйте `[skip ci]`; не пропускайте CI для изменений приложения.
- Сохраняйте совместимость с пользовательской JSON-базой, ручные названия/связи, оценки, разметку и явный выбор очереди. Не используйте повторный импорт как безопасное слияние.
- Не публикуйте ключи TMDB, пользовательскую базу и личные списки. Проверки проводят на временных данных.
- Перенос и удаление фильмов выполняет пользователь. Не добавляйте автоматические операции с фильмами без отдельного согласования; для переименования сохраняйте подтверждение сомнительных связей.
- В облачной задаче используйте существующий изолированный checkout; не создавайте worktree без запроса пользователя.
