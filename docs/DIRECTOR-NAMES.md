# Единые имена режиссёров — предложение для согласования

Статус: концепция, 7 ноября 2026 года. Общий экран и массовая обработка пока не реализованы. Существующая кнопка «Имя режиссёра» уже позволяет задать личное имя и фамилию сортировки, сохраняя прежний ID.

Цель: показывать режиссёров по-русски и сохранять поиск по русскому, латинскому и исходному имени. При этом не пересоздавать режиссёров и не менять связи с фильмами.

## Идентичность и имена

| Данные | Назначение |
| --- | --- |
| `director.id` / ключ `directors` | Постоянный TMDB person ID; именно он определяет человека и используется для запросов |
| `userName` | Привычное русское имя, выбранное пользователем; приоритет отображения |
| `tmdbName` | Сохранённое имя источника; не заменяется введённым переводом |
| `aliases` | Все известные варианты для поиска; исходное написание сохраняется |
| `sortSurname` | Необязательный ключ фамилии для алфавитного указателя; особенно важен для составных фамилий и восточноазиатского порядка слов |

`name` остаётся отображаемым значением для совместимости. Существующие `films.*.dir`, `directorIds`, очереди, избранное, оценки, желания, планы ночей и файлы не пересоздаются и не переназначаются. Кинематограф определяется странами фильма, а не языком имени режиссёра.

## Предлагаемый общий экран

В библиотеке — «Имена режиссёров». Фильтры: все, без русского отображаемого имени, не проверены, изменены в текущем сеансе. Поиск работает по всем вариантам имени и фильмам.

Строка показывает имя в библиотеке, исходное имя TMDB и варианты, ID/ссылку на профиль TMDB, несколько связанных фильмов с годами, поле русского имени и фамилию для сортировки. Примеры фильмографии помогают понять, кому принадлежит незнакомое имя.

Можно запросить варианты имён по существующему TMDB ID. Русское написание, если оно есть в ответе, используется как предложение для просмотра. Прежнее личное имя не перезаписывается автоматически. Если нужного имени нет, пользователь вводит его вручную. Наличие кириллицы само по себе не гарантирует русское написание, а механическая транслитерация не всегда совпадает с привычным именем.

## Применение

Изменения сначала редактируются как предложения и показываются «было → станет». Пользователь применяет выбранные имена одним действием. Непроверенные строки можно отложить. Сохранение должно быть атомарным, с возможностью отменить именно изменения имён; для этого хранится прежнее значение каждого изменённого ID. Подтверждение должно учитывать, не было ли имя изменено после подготовки предложения.

Одинаковые имена разных людей не означают дубликат. Разные TMDB ID не объединяются автоматически по тексту, переводу или транслитерации. Сомнительная идентичность требует отдельной проверки по профилю и фильмографии.

Все экраны должны брать имя по ID из единого источника отображения, включая библиотеку, фильмографию, подбор ночи и варианты в дисковом разборе. Кэшированные строковые имена кандидатов должны служить запасным вариантом, а не перекрывать личное имя известного ID.

## Рекомендуемый порядок работы

1. Исправить понятность и работу фильтров «Собрать ночь».
2. Согласовать общий экран имён, затем реализовать его без повторного импорта библиотеки.
3. Сначала проверить режиссёров без русского имени; готовые варианты TMDB подтвердить, остальные заполнить вручную.
4. Проверить поиск, алфавит, избранное и подбор на тех же TMDB ID.

Полный автоматический перевод всей библиотеки и массовая замена имён по одному совпавшему написанию не предлагаются: задача требует сохранения личных решений и идентичности режиссёров.
