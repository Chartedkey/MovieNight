# Movie Night

Личное приложение для Windows: очереди фильмов по режиссёрам, разбор после просмотра и сканирование дисков, а в следующем этапе подбор киноночи.

## Документация

[Полное описание программы и план развития](docs/PROGRAM.md): готовые функции, сценарии, ограничения, архитектура, данные, история версий и правила дальнейшей разработки. Документ нужно обновлять при изменении поведения программы.

## Установка

Скачай `Movie Night Setup *.exe` со страницы [Releases](https://github.com/Chartedkey/MovieNight/releases). Программа не подписана сертификатом, поэтому Windows может показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае». Новые версии программа предложит установить сама.

## Данные

Список фильмов, оценки и ключ TMDB хранятся только на компьютере пользователя (`%APPDATA%\Movie Night`) и в репозиторий не попадают.

## Разработка

```
npm install
npm test
npm start
```

`scripts/build_seed.py` собирает файл начальных данных из таблицы. Сборку каждой новой версии и её публикацию необходимо предварительно согласовать с владельцем. Выпуск автоматически запускается при изменении `package.json` в `main`; обычный CI также выполняет Windows-сборку. Подробности — в полном описании программы.

Данные о фильмах предоставляет [TMDB](https://www.themoviedb.org/). Этот продукт использует API TMDB, но не одобрен и не сертифицирован TMDB.
